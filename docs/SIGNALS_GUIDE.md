# 📊 Руководство по интерпретации сигналов ставок

> Что означает каждое число в сигнале? На что ставить? Как это реализовано?

## 1. Анатомия сигнала

### Пример теннисного сигнала (приоритетный)

```
🟢 🎾 Matteo Berrettini победит Juan Manuel Cerundolo
Время: 01.06 14:20 UTC
Коэффициент: 1.67 | Вероятность модели: 77.1%
Рынок после снятия маржи: 58.4% | Edge: 28.71%
• Покрытие: clay | Рейтинг: #105 vs #56
• ELO: 68.2% | Форма: 40.0%
• Подача: 69.2% | Отдых: 26 дн.
• H2H-поправка: -0.0% | Модель: markov+elo
```

### Декодирование (что означает каждое число)

| Поле | Значение | Интерпретация |
|---|---|---|
| **Коэффициент (1.67)** | букмекер B365 | Если поставить 1 единицу и выиграть → получить 1.67 единиц |
| **Вероятность модели (77.1%)** | ML predict | Наша модель считает, что Berrettini выиграет с вероятностью 77% |
| **Рынок после маржи (58.4%)** | implied prob | "Справедливая" вероятность без маржи букмекера |
| **Edge (28.71%)** | 77.1% - 58.4% | **КЛЮЧЕВОЕ:** разница между моделью и рынком — наше преимущество |
| **ELO (68.2%)** | рейтинг Berrettini | На основе исторических результатов против #105-#56 соперников |
| **Форма (40.0%)** | недавняя форма | Недавние матчи Berrettini (% побед в последних 5-10) |
| **Подача (69.2%)** | serve win % | Berrettini выигрывает свои поданные геймы в 69.2% случаев |
| **H2H-поправка (-0.0%)** | история встреч | Поправка на личные встречи: 0% = нейтрально |
| **Отдых (26 дн.)** | days since match | Berrettini отдыхал 26 дней перед этим матчем |

## 2. Правило: На что ставить?

### 📌 Простое правило: Ставь ПРОТИВ рынка

**Если Edge > 0** → поставь на выбор модели

```
Пример:
  Модель говорит:    77.1%
  Рынок говорит:    58.4%
  Разница (Edge):   28.71%  ← ПОЛОЖИТЕЛЬНОЕ, значит СТАВИМ
  
Выбор: Matteo Berrettini ML (1.67)
```

**Если Edge < 0** → НЕ ставим (рынок прав, модель ошибается)

```
Пример:
  Модель говорит:    40%
  Рынок говорит:    45%
  Разница (Edge):   -5%     ← ОТРИЦАТЕЛЬНОЕ, НЕ СТАВИМ
```

## 3. Уровни сигналов

### 🟢 **PRIORITY сигналы** (зелёные)
- **Edge > 5%** — модель сильно уверена, рынок ошибается
- **Реакомендация:** рассмотри ставку
- **Что можно поставить:** 0.5-1.0 единиц (Kelly fraction 25-50%)
- **Статистика:** в среднем должны быть прибыльными на длинной дистанции

### 🟡 **WATCHLIST сигналы** (жёлтые)
- **Edge 2-5%** — модель немного уверена, но хороших шансов нет
- **Реакомендация:** наблюдай, не ставь
- **Используется для:** обучения модели, скопления данных
- **Статистика:** слабое преимущество, дисперсия велика

### ⏸️ **BLOCKED сигналы** (заблокированы)
- **Edge < 2%** — слишком близко к fair odds
- **Причины:** коэффициент уже скорректировался, травмы обновились, время истекло
- **Реакомендация:** игнорируй

## 4. Работа системы (Pipeline)

### 📈 Как генерируются сигналы?

```
┌─────────────────────────────────────────────────────────┐
│  1. FETCH LIVE ODDS                                     │
│     The Odds API → коэффициенты из B365, Pinnacle, ...  │
│     Обновляется каждые 3 часа автоматически             │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  2. NORMALIZE & DEVIG                                   │
│     Удалить маржу букмекера (B365 маржа ~4-5%)         │
│     Расчёт "справедливой" вероятности рынка             │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  3. RUN ML MODELS                                       │
│     Football: Dixon-Coles (Poisson) модель              │
│     Tennis: ELO + Markov chain модель                   │
│     Предсказать вероятность каждого исхода              │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  4. CALCULATE EDGE & FILTER                             │
│     Edge = model_prob - market_prob                     │
│     Если Edge > threshold → SIGNAL ✅                    │
│     Иначе → БЛОКИРУЕТСЯ                                  │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  5. TELEGRAM NOTIFICATION                               │
│     Отправить сигнал в Telegram чат                     │
│     (или dry-run → только в логи)                       │
└──────────────────┬──────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────────┐
│  6. SAVE TO LEDGER                                      │
│     Сигнал сохраняется в data/core/paper_signal_ledger  │
│     Отслеживается: статус, исход, P&L                   │
└─────────────────────────────────────────────────────────┘
```

**Реальный сценарий на 01.06.2026:**
1. ✅ API fetch: коэффициенты на Berrettini @1.67
2. ✅ Devig: маржа B365 удалена, рынок = 58.4%
3. ✅ ELO model: Berrettini выиграет 77.1% (рейтинг + форма + подача)
4. ✅ Edge calc: 77.1% - 58.4% = 28.71% → PRIORITY
5. ✅ Telegram: отправить в чат (или dry-run логи)
6. ✅ Ledger: signal_id + entry_odds + model_prob сохранены

## 5. Где это реализовано в коде?

### 📁 Файлы сигналов

| Файл | Ответственность |
|---|---|
| `src/signals/football_runtime_scan.py` | Генерация футбольных сигналов (Dixon-Coles) |
| `src/signals/tennis_runtime_scan.py` | Генерация теннисных сигналов (ELO + Markov) |
| `src/signals/tennis_signal_scan.py` | Основная ELO/Markov логика для теннис |
| `src/models/production_signal_engine.py` | Edge вычисление + фильтрация |
| `src/cron/run_signals.py` | Оркестрация всего pipeline → ledger |
| `src/web/today_picks.py` | Форматирование для Telegram (видишь в боте) |
| `src/models/signal_ledger.py` | Хранилище сигналов (JSON) |
| `src/models/feedback_policy.py` | Правила: priority/watchlist/blocked |

```python
# scheduler.py — каждые 3 часа

    return subprocess.run([
        'python', '-m', 'src.cron.run_signals'
    ])

# Результат → ledger → Telegram
```

## 10. Часто задаваемые вопросы

### Q: Реальные ли это ставки?
**A:** НЕТ. Paper trading only — система считает прибыль/убыток, но не размещает реальные ставки.

### Q: Сколько заработать?
**A:** Зависит от edge и дисперсии. При edge 5% и 100 ставках, ожидание ~+5%, но std.dev может быть ±10%.

### Q: Почему "Манчестер Юнайтед" на коэффициент 2.15?
**A:** Модель видит выгодную цену (model_prob=68% > рынок=58%), поэтому edge=10%.

### Q: Как проверить сигналы после матча?
**A:** `/history` в Telegram боте → видишь исход, P&L, edge реализованный (CLV).

### Q: Можно ли изменить edge threshold?
**A:** Да, в `src/models/feedback_policy.py`:
```python
PRIORITY_THRESHOLD = 5.0  # % edge
WATCHLIST_THRESHOLD = 2.0  # % edge
```
